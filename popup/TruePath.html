TRUEPATH ultimate : XPath on click    
  • Right click on the target element to generate the relative XPath
  • You can use the Dev tools To create the custom XPath in seconds
  • TruePath now auto generate the Page Object Model code for Java, C#, and Robot Framework.

TRUEPATH Locator Analyser is the page object locators analyzer of the target page written in Java. A window will display once the analysis is done, in case of no matching locators found, no window will display. The page with the following locator format is supported now.The current release doesn't support the CCS locators.
@FindBy(LocatorType ="element") public WebElement element;

The following are the meaning of symbols:
   ☓ -The element is not present on the page
   ✓ -The element is present on the page
   ✓ -Multiple elements are present on the page
